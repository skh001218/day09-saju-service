# 001: 쉬운 기본 성향 한 문장

## 목적

사주를 처음 접하는 사람이 계산 결과의 의미를 한 문장으로 읽을 수 있게 합니다.

## 동작

1. 기존 양력 생년월일·출생시간 입력과 사주 계산을 유지합니다.
2. 계산된 일간의 오행(목·화·토·금·수)에 따라 아래 문장 하나를 결과 상단에 표시합니다.
3. 기존 년주·월주·일주·시주와 일간은 그대로 표시합니다.
4. 잘못된 입력에서는 계산 결과와 성향 문장을 표시하지 않고 기존 오류 안내를 보여줍니다.
5. 문장은 전통적 사주 해석을 쉽게 풀어쓴 참고 정보이며 실제 성격을 단정하지 않는다는 안내를 덧붙입니다.
6. 생년월일은 브라우저의 기존 날짜 선택기, 출생시간은 기존 시간 선택기를 사용합니다. 브라우저에 보이는 표시는 기기 언어 설정에 따르되 계산에 쓰는 값은 `YYYY-MM-DD`와 24시간제 `HH:mm`입니다.
7. 날짜 선택 범위는 1990년 1월 1일부터 한국 시간 기준 오늘까지, 시간은 00:00부터 23:59까지 1분 단위입니다. 입력칸을 벗어날 때 비정상 값은 지우고 안내하며 계산 단계에서도 실제 날짜·미래 날짜·시간을 다시 검사합니다.

## 오행별 문장

| 일간 오행 | 표시할 문장 |
|---|---|
| 목 | 새로운 것을 배우고 차근차근 성장하는 성향으로 풀이해요. |
| 화 | 생각과 마음을 활발하게 표현하는 성향으로 풀이해요. |
| 토 | 차분하게 중심을 잡고 맡은 일을 꾸준히 이어가는 성향으로 풀이해요. |
| 금 | 기준을 세우고 일을 분명하게 정리하는 성향으로 풀이해요. |
| 수 | 상황을 살피고 유연하게 생각하는 성향으로 풀이해요. |

## 완료 조건

- 다섯 오행에 각각 정확한 문장 하나가 대응합니다.
- `2000-01-01 12:00` 입력에서 토의 문장과 기존 사주 네 기둥이 보입니다.
- 빈 출생시간과 1990년 이전 날짜에서 성향을 임의로 표시하지 않습니다.
- `npm run check`와 실제 브라우저 확인이 통과합니다.
