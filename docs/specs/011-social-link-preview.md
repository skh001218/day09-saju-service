# 011: 배포 링크 오행 미리보기

## 목적과 범위

서비스 URL을 공유할 때 이미지 없는 링크 대신 오행을 한눈에 알아볼 수 있는 미리보기를 제공합니다. 개인 사주 결과와 무관한 정적 대표 이미지입니다.

## 요구사항

1. 1200×630 PNG에 목·화·토·금·수의 이름과 각각을 나타내는 도형, 서비스 제목을 읽기 쉽게 배치합니다. 원본 도안도 저장해 나중에 수정할 수 있게 합니다.
2. 홈페이지의 Open Graph 및 Twitter 메타데이터에 절대 URL로 접근 가능한 이미지가 연결됩니다. 큰 이미지 카드와 한국어 제목·설명을 사용합니다.
3. 이미지에는 사용자 입력값·계정 정보·비밀값이 없어야 합니다. 기존 사주 계산과 로그인·해석 흐름은 변경하지 않습니다.
4. 이미지 파일은 배포 시 정적 제공되며, 이미지 요청 실패가 홈페이지 렌더링에 영향을 주지 않습니다.

## 검증 기준

1. 자동 테스트와 빌드에서 이미지 크기·형식, 제목·설명, 메타 태그 연결을 확인합니다.
2. 로컬 HTTP에서 홈페이지의 이미지 메타 태그와 이미지 응답을 확인합니다.
3. 배포 후 실제 URL에서 메타 태그의 이미지 주소가 배포 도메인을 가리키고 PNG가 200으로 응답하는지 확인합니다. 외부 플랫폼의 캐시 반영 여부는 별도로 기록합니다.

## 검증 결과

- 2026-09-23: 구현 전 `https://day09-saju-service.vercel.app/`는 HTTP 200이었지만 `og:image` 및 `twitter:image` 메타 태그가 없었습니다.
- 오행 도안의 PNG를 직접 열어 1200×630 크기와 다섯 도형·한글 이름을 확인했습니다.
- 비구현 테스트 담당이 PNG 형식·크기, 배포 도메인, 메타데이터, 대체 텍스트를 검사하는 테스트 2개를 추가했습니다. PR #5의 변경을 반영한 뒤 `npm run check`의 타입 검사와 전체 테스트 79개가 통과했고, `npm run build`도 통과했습니다.
- 로컬 프로덕션 서버에서 홈페이지 HTTP 200, 절대 URL의 `og:image`·`twitter:image`와 큰 Twitter 카드, 두 PNG 경로 HTTP 200 및 `image/png`을 확인했습니다.
- 실제 배포 도메인에서 새 이미지가 제공되는지와 외부 플랫폼의 미리보기 반영은 배포 후 확인해야 합니다. 따라서 진행 상태는 미완료로 둡니다.
