# 012: 매일 달라지는 운세

## 목적과 범위

사용자가 자신의 사주 결과를 다시 열었을 때, 그날 참고할 만한 짧은 안내를 볼 수 있게 합니다. 출생 사주와 오늘의 일주를 함께 사용하고 날짜별 문구를 결정적으로 선택합니다. 결과는 오락용이며 실제 사건을 예측하거나 행동의 결과를 보장하지 않습니다.

## 사용자 흐름

1. 사용자가 유효한 생년월일과 출생시간으로 **내 사주 알아보기**를 완료하면, 기존 계산 결과와 함께 **오늘의 운세**를 표시합니다. 로그인이나 Gemini 자세한 해석은 필요하지 않습니다.
2. 제목에 기준 날짜를 `YYYY년 M월 D일`로 표시하고, **오늘의 흐름**, **해볼 만한 행동**, **주의할 점**을 각각 짧은 한국어 문장으로 보여줍니다. 오락용 안내라는 문구를 같은 영역에 표시합니다.
3. 저장된 계정 또는 브라우저 기록을 다시 열 때는 저장 당시의 운세를 재사용하지 않고, 그 기록의 유효한 사주 결과와 현재 한국 날짜로 다시 계산합니다.
4. 화면을 열어 둔 채 한국 시간 자정이 지나면 새 날짜의 운세로 갱신합니다. 탭을 다시 활성화하거나 새로고침해도 현재 날짜의 내용이 보입니다.

## 계산과 문구 규칙

- 날짜 기준은 `Asia/Seoul`의 양력 달력 날짜입니다. 하루의 운세는 00:00부터 다음 날 00:00 직전까지 동일합니다. 서버와 브라우저의 로컬 시간대 설정에 의존하지 않습니다.
- 해당 날짜의 일주는 `lunar-javascript`를 사용하는 `lib/saju`에서 한국 시간 정오(12:00)를 대표 시각으로 계산합니다. 이렇게 얻은 일주의 천간·지지와 기존 출생 사주의 일간을 입력으로 사용합니다. 정오를 사용해 하루 중 23시 일자 변경 규칙 때문에 운세가 중간에 바뀌지 않게 합니다. 출생 사주 계산 규칙은 바꾸지 않습니다.
- 일간과 오늘 일주의 대표 오행 관계를 코드의 명시적 규칙으로 분류합니다. 단순 오행 개수를 강약·결핍·길흉 점수로 해석하지 않습니다. Gemini에게 일주나 오행 관계 계산을 맡기지 않습니다.
- 각 분류별로 사람이 검토한 문구 후보를 준비합니다. 후보 선택은 유효한 출생 사주, 기준 날짜, 문구 버전을 입력으로 하는 안정적인 방식으로 결정합니다. 새로고침, 다른 기기, 반복 조회에서 같은 입력은 같은 문구를 반환합니다. 단순 난수나 재조회마다 바뀌는 생성 결과를 쓰지 않습니다.
- 날짜가 바뀌면 기준 일주와 문구 선택 입력을 다시 계산합니다. 모든 연속 날짜에 실제 표시 문장이 달라지는지 검증하며, 같은 문장 세 개가 다음 날 그대로 반복되지 않도록 후보 선택 규칙을 둡니다.
- 문구는 실천 가능한 가벼운 제안으로 작성합니다. 건강 진단, 투자·재정 결정, 합격·이별·사고 등 미래 사건의 단정, 불안을 주는 표현은 사용하지 않습니다.

## 데이터와 실패 조건

- 기존 `SajuChart`와 날짜만 사용합니다. 일일 운세를 계정 DB나 `localStorage`에 별도로 저장하지 않고, 운세 조회를 위한 새 Gemini 호출도 하지 않습니다.
- 출생 사주가 없거나 손상되었거나 오늘 일주 계산이 실패하면 개인화된 운세를 만들지 않습니다. 해당 영역에 계산할 수 없다는 안내와 재시도 방법을 보여주며, 기존 유효한 사주 결과는 유지합니다.
- 날짜 변경 직후 계산이 실패해도 전날 운세를 오늘의 운세로 표시하지 않습니다.
- 입력값이나 사주 정보는 운세 계산을 이유로 새로운 외부 서비스에 전송하지 않습니다.

## 범위에서 제외

- 월간·연간 운세, 주제별 운세, 푸시 알림, 운세 기록과 공유
- Gemini가 매일 문장을 생성하는 기능, 길흉 점수나 실제 적성·성과 예측
- 기존 Gemini 자세한 해석·로그인·계정 기록의 정책 변경

## 완료 조건

1. 유효한 새 계산과 저장 기록 재열기에서 현재 한국 날짜의 운세 세 문장과 오락용 안내가 표시됩니다. 같은 사주·날짜의 결과는 반복 조회와 새로고침 후에도 같습니다.
2. 한국 시간 자정 전후와 화면을 계속 열어 둔 경우를 포함해 날짜 갱신을 확인합니다. 브라우저나 서버의 시간대가 달라도 같은 한국 날짜를 사용합니다.
3. 서로 다른 날짜의 일주 계산과 연속 날짜 문구 변경을 확인합니다. 특히 23:00~23:59에도 표시 날짜와 운세는 그날 기준으로 유지됩니다.
4. 유효하지 않은 입력, 손상된 저장 기록, 일주 계산 실패에서는 운세를 꾸며내지 않고 기존 계산·오류 흐름을 유지합니다.
5. 관련 자동 테스트, 타입 검사, 빌드와 실제 화면 검증을 수행합니다. 기존 사주 계산, 자세한 해석, 기록 재열기 기능도 다시 확인하고 결과를 아래에 기록합니다.

## 검증 결과

- 2026-09-28: `lib/saju`에서 한국 날짜의 정오 일주와 출생 일간의 오행 관계를 계산하고, 검토한 문구 후보 중 날짜·출생 사주에 따라 결정적으로 선택하도록 구현했습니다. 새 계산 및 기록 재열기는 같은 화면 컴포넌트를 사용하며, 한국 시간 자정과 탭 재활성화 시 날짜를 갱신합니다.
- 비구현 테스트 담당이 한국 날짜 경계, 정오 일주, 같은 날짜의 결정성, 연속 31일의 문구 변경, 손상된 사주·날짜 거부, 화면 연결과 갱신 조건을 검증하는 테스트를 추가했습니다. 주 에이전트의 `npm run check`에서 타입 검사와 전체 테스트 85개가 통과했고, `npm run build`도 통과했습니다.
- 로컬 브라우저에서 이전 브라우저 기록 `2000-01-01 12:00`을 다시 열어 2026년 9월 28일의 오늘의 운세 세 항목과 오락용 안내가 표시되는지 확인했습니다. 같은 입력으로 새 계산을 다시 실행해 상세 해석만 초기화되고 운세는 유지되는 것도 확인했습니다. 기존 사주 네 기둥·오행 개수·저장 해석도 함께 표시됐습니다.
- 이 환경에는 Google 로그인 설정이 없어 계정 기록 재열기의 실제 화면은 확인하지 못했습니다. 계정 기록과 브라우저 기록은 동일한 결과 화면을 사용하며, 기존 계정 기록 자동 테스트는 통과했습니다.
