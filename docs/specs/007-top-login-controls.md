# 007: 로그인 영역을 페이지 상단으로 이동

## 목적

첫 화면에서 Google 로그인과 현재 로그인 상태를 제목보다 먼저 확인할 수 있게 합니다.

## 요구사항

1. 로그인 영역은 페이지 콘텐츠의 맨 앞, 제목과 소개 문구보다 위에 표시합니다.
2. 로그인·로그아웃, 오류 안내, 사주 입력·계산·기록 기능은 기존 동작을 유지합니다.
3. 좁은 화면에서도 로그인 안내와 버튼이 잘리지 않고 읽히도록 합니다.

## 완료 기준

- 페이지 구조와 실제 화면에서 로그인 영역이 제목보다 앞에 보입니다.
- 관련 자동 테스트, 타입 검사와 기존 기능 검증을 통과합니다.

## 검증 결과

- `npm run typecheck`, `npm run build`, `npm test` 통과(66개).
- 로컬 서버의 실제 HTML에서 로그인 영역 → 제목 → 입력 카드 순서를 확인했습니다.
- 브라우저 화면에서 로그인 안내와 버튼이 제목 위에 표시되는 것을 확인했습니다. 현재 로컬 환경은 Google 로그인 설정이 없어 버튼이 비활성화되며, 이는 기존 설정 상태입니다.
