# 009: 내 오행 유형과 상생·상극 그림

## 목적과 범위

사주 계산 결과에서 내 오행 유형을 바로 알아보고, 첨부한 오행 오각형 그림처럼 다섯 오행 사이의 전통적인 흐름을 한눈에 볼 수 있게 합니다. **내 오행 유형은 계산된 일간의 오행**입니다. 기존 오행 개수는 네 기둥의 대표 오행 8개를 센 별도 정보이므로 최다 개수를 내 유형으로 고르지 않습니다.

## 화면

1. 정상 계산 결과의 오행 영역에 목·화·토·금·수 다섯 원을 오각형으로 배치합니다. 내 오행 원에는 테두리와 `나` 표시를 더하고, 제목에서도 `내 오행 유형: ○`를 텍스트로 보여줍니다.
2. 바깥의 진한 화살표는 **상생(돕는 흐름)** 목→화→토→금→수→목, 안쪽의 속이 빈 화살표는 **상극(견제하는 흐름)** 목→토→수→화→금→목입니다. 색만으로 구분하지 않도록 범례와 두 순환을 문자로도 표시합니다.
3. 사용자의 오행을 기준으로 `나를 돕는`, `내가 돕는`, `나를 견제하는`, `내가 견제하는` 오행을 텍스트로 보여줍니다. 상극을 사람에 대한 부정적 판단으로 표현하지 않습니다.
4. 작은 화면에서도 그림이 영역 안에 맞고 글자를 읽을 수 있게 합니다. SVG에는 설명 가능한 이름을 주며, 그림과 동등한 핵심 정보가 주변 텍스트에도 있습니다.
5. 그림은 전통적인 오행의 관계를 설명합니다. 기존 Gemini의 `잘 맞는 사람 유형` 추천과 동일한 판정으로 취급하지 않으며, 실제 두 사람의 궁합이나 성격을 단정하지 않는다는 안내를 표시합니다.

## 데이터와 실패 조건

- 기존 `chart.dayMaster.element`만 사용합니다. 로그인, Gemini, 외부 API, 저장 구조, 사주 계산 코드는 변경하지 않습니다.
- 목·화·토·금·수 이외의 값이거나 누락되면 내 유형이나 개인화된 관계를 추측해 만들지 않고 안내를 표시합니다. 정상 기록을 다시 열면 저장된 차트의 일간으로 같은 그림을 보여줍니다.
- 새 입력을 시작해 기존 차트를 지우거나 입력 오류가 나면 그림도 보이지 않습니다.

## 범위에서 제외

- 두 사람의 생년월일 비교, 개인 궁합 점수, 좋은·나쁜 상대 판정
- 오행 강약·용신·희신·부족함 판정, AI 생성 그림 또는 추가 Gemini 호출

## 완료 조건

1. 다섯 일간 유형의 상생·상극 네 방향이 올바르게 연결됩니다. 두 순환의 모든 화살표가 보이고 범례와 텍스트가 일치합니다.
2. 정상 계산과 기록 재열기에서 내 유형이 일간에 맞게 표시되며 기존 8자 개수와 혼동되지 않습니다.
3. 손상된 값, 입력 오류에서 잘못된 개인화 결과가 표시되지 않습니다.
4. 관련 자동 테스트, 타입 검사, 빌드, 실제 브라우저의 데스크톱·모바일 화면과 기존 계산 흐름을 확인합니다.

## 검증 결과

- 2026-09-23: 비구현 테스트 담당이 상생·상극 순환과 다섯 일간의 네 관계, 손상값 거부, 원본 차트 무변경, 화면 연결·SVG 접근성·범례 테스트 5개를 추가했습니다.
- 주 에이전트의 최종 `npm run check`에서 TypeScript 검사와 전체 자동 테스트 74개가 통과했고, `npm run build`도 통과했습니다.
- 로컬 브라우저에서 `2000-01-01 12:00`을 계산해 일간 토, 상생의 화·금, 상극의 목·수, 다섯 원·두 화살표 순환·주의 문구를 확인했습니다. 계산 결과는 로그인 없이 나타났습니다. 입력을 바꾸면 그림이 사라지는 것도 확인했습니다.
- 데스크톱과 너비 390px 모바일 화면에서 그림·범례·관계 설명을 확인했고, 모바일 가로 넘침은 없었습니다. 기록 재열기는 같은 `chart` 렌더링 경로를 사용함을 자동 테스트로 확인했습니다. 개발 환경에 저장 기록이 없어 브라우저에서 실제 기록 재열기는 확인하지 못했습니다.
